# 科技英语 · 六日复习

线上地址：<https://buxlc.github.io/glass-ore-review/>

一个纯静态的科技英语自测站，面向「玻璃史 / 科技英语」与「矿物加工」两条内容线。UI 采用暖米色、墨色与陶土橙的编辑式风格，包含六日计划、术语卡、自测、当天错题回顾和全局错题本。

## 内容规模

- **156 个去重术语**
  - 110 个英语词条（玻璃史、玻璃工业、市场与环保）
  - 46 个矿物加工 / 冶金概念
- **13 个工艺专题**：湿法冶金、火法冶金、采矿、矿物加工、破碎磨矿分级、重选、磁选、浮选、电选、磁化焙烧-磁选、直接还原、高磷鲕状赤铁矿、矿物资源工程
- **28 类设备**：破碎、磨矿、分级、重选、磁选、浮选、电选
- **6 天结构**：5 天主题输入 + 第 6 天全库混合测与设备速查

## 去重说明

原始列表中的以下内容被合并或去重：

- `raw material` / `raw materials` → 合并为 `raw material(s)`
- `manufacturer` / `manufacturers` → 合并为 `manufacturer(s)`
- 重复出现的「重选 / 磁选 / 浮选 / 电选」只保留一条术语记录
- `manufacturing`（制造业/生产）与 `manufacturer(s)`（制造商）含义不同，保留为两条
- `glassworks` 与 `glasshouse` 都涉及玻璃厂，但后者在现代英语中也指温室，保留并注明差异

## 功能

- **六日总览**：完成进度、推荐下一日、六日日程
- **灵活范围**：按每日进度抽 12 词；也可自由选择 10 / 20 / 30 / 50 词，或一次复习全库 156 词
- **术语卡**：英文 / 中文 / 搭配或工艺提示；可一键遮挡中文自测
- **双重验证**：每个词都要通过“看英文选释义”和“看中文拼英文”两关；只有两关都通过才计为完全掌握
- **错词回炉**：答错的词会在 5 题后再次出现；如果又错，就继续往后放，直到通过
- **即时反馈**：正确答案、记忆提示、回炉提示
- **错误率排行榜**：本次结束后看本次错词排行；错题本页保留全库累计排行榜
- **全局错题本**：未订正 / 今日 / 已订正 / 全部筛选；释义与拼写都通过才移出“未订正”
- **工艺图鉴与设备速查**：把词汇放回流程
- **本地持久化**：进度、掌握度与错题保存在浏览器的 `localStorage`，不上传服务器
- **移动端适配**：范围选择、答题、反馈和排行榜均按手机屏幕重排
- **键盘操作**：`1–4` 选择，`Enter` 继续；拼写题 `Enter` 检查

## 本地运行

无需构建工具，直接打开 `index.html` 即可；或启动任意静态服务器：

```bash
python -m http.server 8123
```

然后访问 `http://127.0.0.1:8123/`。

## 文件

- `index.html` — 页面结构
- `styles.css` — Anthropic 风格的暖色编辑式样式
- `data.js` — 术语、工艺、设备数据
- `app.js` — 路由、术语卡、自测、错题本逻辑
- `.nojekyll` — GitHub Pages 静态文件直出

## 部署

站点通过 GitHub Pages 托管。构建产物为仓库根目录的静态文件，无需 CI。
